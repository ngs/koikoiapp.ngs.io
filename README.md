# koikoiapp.ngs.io

Promotional site for [Koikoi - Japanese Card Game](https://apps.apple.com/app/koikoi-japanese-card-game/id6797163218), the hanafuda Koi-Koi app built in [ngs/koikoi-swift](https://github.com/ngs/koikoi-swift).

Built with [Hugo](https://gohugo.io) and deployed to GitHub Pages on every push to `master` (see `.github/workflows/deploy.yml`).

## Structure

```
content/<lang>/_index.md          # landing page — all copy lives in the front matter
content/<lang>/privacy/index.md   # privacy policy — linked from App Store Connect
i18n/<lang>.yaml                  # navigation, footer and screenshot captions
layouts/                          # baseof / index / single + header and footer partials
static/img/screenshots/<lang>/    # app screenshots (en, ja)
static/img/cards/                 # hanafuda cards used as hero decoration
static/img/appstore-banner/       # App Store badges (en, ja)
Scripts/assets.sh                 # regenerates every image asset from the app repository
hugo.toml                         # site config, two languages
```

The site ships in two languages, `en` and `ja`. English is served from the root and Japanese from `/ja/`. Each App Store locale's `marketing_url` points at the matching page here and its `privacy_url` at `/privacy/` under it.

## Development

```bash
hugo server            # http://localhost:1313
hugo --gc --minify     # build into public/
```

## Updating the images

Every image under `static/img/` except the App Store badges and `og.png` is generated from the app repository by `Scripts/assets.sh`. Run it with the path to a checkout of `ngs/koikoi-swift` (it defaults to `../koikoi-swift`):

```bash
Scripts/assets.sh ../koikoi-swift
```

It needs `cwebp` (`brew install webp`), `rsvg-convert` for the cards (`brew install librsvg`; without it the script falls back to the QuickLook renderer built into macOS) and `swift` for the app icon. Intermediate PNGs go to a temporary directory, and only the final WebP files land in the repository.

Screenshots come from `fastlane/screenshots/` in the app repository, once per language (`en-US` becomes `en`):

The five hero cards are rasterized from `Resources/Assets.xcassets/Cards/<name>.imageset/<name>.svg` to 374px wide: `matsu-tsuru`, `sakura-maku`, `susuki-tsuki`, `yanagi-michikaze` and `kiri-hoo`.

`icon.png` comes from the app icon artwork: the script composes `AppIconArtwork.svg` onto the icon's cream background and rasterizes it to 1024px with `Scripts/render_icon.swift` from the app repository, which needs a Swift toolchain. The corners stay square in the file and are rounded in CSS. `icon-512.png` is then derived from it with `sips`.

`og.png` (1200x630, used for Open Graph and Twitter cards) is a one-off composition and is not regenerated by the script.
