# shiomi-app.ngs.io

Promotional site for [Shiomi - Simple Tide Chart](https://apps.apple.com/app/shiomi-simple-tide-chart/id6754582175), the tide app built in [ngs/tides-swift](https://github.com/ngs/tides-swift).

Built with [Hugo](https://gohugo.io) and deployed to GitHub Pages on every push to `master` (see `.github/workflows/deploy.yml`).

## Structure

```
content/<lang>/_index.md          # landing page (front matter drives the hero)
content/<lang>/privacy/index.md   # privacy policy — linked from App Store Connect
i18n/<lang>.yaml                  # navigation, footer and screenshot captions
layouts/                          # baseof / index / single + header and footer partials
static/img/screenshots/<lang>/    # app screenshots (en, de, es, fr, ja, ko, zh-hans)
static/img/appstore-banner/       # localized App Store badges
hugo.toml                         # the 34 languages the app ships in
```

The 34 languages match the App Store locales in `fastlane/metadata/` of the app repository (App Store regional variants — `en-GB`, `es-MX`, `fr-CA` and so on — share one page). Each locale's `marketing_url` points at `/<lang>/` here and its `privacy_url` at `/<lang>/privacy/`; English uses the site root.

Screenshots exist in seven languages only (they come from `ngs/tides-screenshots`, resized for the web); every other language falls back to the English set, which `layouts/index.html` resolves through `params.screenshotLanguages` in `hugo.toml`.

## Development

```bash
hugo server            # http://localhost:1313
hugo --gc --minify     # build into public/
```

## Updating the screenshots

They are generated by `Scripts/screenshots.sh` in the app repository and stored in the `ngs/tides-screenshots` submodule at `fastlane/screenshots`. To refresh them here, resize the new ones into `static/img/screenshots/<lang>/`:

| Site file | Source | Size |
|---|---|---|
| `chart-iphone.jpg` | `ios/<locale>/01_chart_iphone.png` | 660px wide |
| `calendar-iphone.jpg` | `ios/<locale>/02_calendar_iphone.png` | 660px wide |
| `locations-iphone.jpg` | `ios/<locale>/03_locations_iphone.png` | 660px wide |
| `chart-mac.jpg` | `mac/<locale>/01_chart_desktop.png` | 1440px wide |
| `tide-watch.png` | `ios/<locale>/02_tide_watch.png` | as-is (416x496) |
| `chart-vision.jpg` | `visionos/<locale>/01_chart_vision.png` | 1920px wide |
